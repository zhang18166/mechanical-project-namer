## 实现范围

标准库http.server负责HTTP解析，http.client负责客户端流式传输；不新增HTTP第三方依赖，不自行实现HTTP解析或加密算法。独立服务只绑定127.0.0.1，前台运行，拒绝Origin及非本机Host，不提供CORS/公开注册/匿名分享/任意URL抓取。仅为回环实验，不能用于公网；Ubuntu、HTTPS、正式身份及安全部署均未验证。

维护脚本预置publisher（read/publish/download）、reader（read）、outsider（无项目权限）。256位随机临时Bearer凭据仅写仓库外配置，服务保存SHA-256，标准hmac.compare_digest比对；错误响应不返回路径/令牌，HTTP访问日志关闭。Windows文件ACL尚未单独验收；配置目录必须私有，不能因未入Git就假定已经加密或具有完善系统权限隔离。

远端项目是独立UUID。维护配置明确授权`(归档store_id, projects.id) → remote_project_uuid`。相同本地ID但不同store不能自动合并；恢复副本保留store_id，只有预置的同一逻辑来源映射才可访问。项目显示名不用于身份判断。HTTP不信任自报owner/admin字段。

发布白名单只有store、local_project、version UUID、label及文件path/role/size/SHA-256。源绝对路径、业务数据库、备份清单、恢复记录、设置和日志不发送。仅接受列出的CAD/STEP/GLB/PDF/STL及txt/csv附件扩展名；数据库、JSON设置、证书、压缩包等拒绝。扩展名白名单不是内容保密性鉴定，仍仅允许虚构样本和人工审查的资料。本轮未解析/执行CAD或自动转换格式。

## 协议1接口

所有路由先认证；任务及文件请求再核对服务端项目权限。

| 方法/路由 | 权限及用途 |
| --- | --- |
| GET /info | 已认证；服务UUID、协议及容量 |
| POST /projects/{project}/tasks | read+publish；固定任务ID/项目/版本/清单绑定 |
| GET /projects/{project} | read；完整版本列表和实时健康状态 |
| GET /tasks/{task} | read；清单、状态、已校验文件索引 |
| PUT /tasks/{task}/files/{index} | publish；独立暂存、流式接收、大小及哈希校验 |
| POST /tasks/{task}/commit | publish；整份复核、提交，重复调用幂等 |
| POST /tasks/{task}/cancel | publish；未完成任务取消，完成版本不删除 |
| GET /tasks/{task}/files/{index} | download；仅健康完整版本，元数据read不等于下载权 |

状态持久化为receiving/complete/cancelled；封存目录为文件系统中间证据。先验证文件，再构建封存目录并复核副本，排他目录提交，随后登记SQLite完成。文件提交后数据库未登记时，任务查询复核目录并补记；已登记但文件缺失/损坏则healthy=false，下载拒绝。封存中途遗留、未知/不一致目录不自动清理或接管，需要保留现场处理；这部分故障闭环尚未全面验收。

同任务内容冲突拒绝；同项目已有活动任务则拒绝另一新任务。单实例OS锁及单线程HTTP服务串行操作，取消/提交有顺序，已成功版本不覆盖。接收和封存副本分开，不以硬链接替代独立复制。无跨项目全局去重，无分布式事务。

客户端只发布重新校验通过的完整快照，任务ID由目标服务/远端项目/逻辑来源/版本稳定推导。重试查询服务持久任务并跳过已校验文件；中断文件从头传，不支持字节级续传。提交响应丢失后查询实际状态。目标服务分别命名空间，不显示腾讯云/飞牛成功。**尚无完整的客户端多目标发布状态台账**，不能把目前的稳定任务ID推导宣传为全部客户端重启场景已验证。

## 限额与文件安全

实验限额：单文件16MiB、版本总量64MiB、100文件、JSON请求2MiB、未完成任务32、总任务256、存储文件256MiB；复制封存也检查空间，另留32MiB余量。单请求处理并发1，连接空闲超时10秒，接收循环期限30秒。不能将这些限制或回环速度当作大装配、公网6Mbps或生产性能承诺。请求头慢速攻击、全局速率/完整并发矩阵未验收，不可公开监听。

保存位置由服务任务UUID/数字文件索引生成，不使用客户端绝对路径。清单拒绝越界/绝对/设备/ADS/大小写与NFC冲突。所有常用路径检查重解析/符号链接；服务私有根仍属于本机信任边界，不提供对恶意本机管理员任意改盘的防护认证。失败的部分文件保留为暂存证据，不列入版本文件。没有自动历史删除/垃圾回收。

下载只写新目录，在独立暂存中流式接收并按清单校验后提交。当前未完成完整的下载目录重叠/磁盘资源故障矩阵，不能视为成熟缓存系统。没有缓存淘汰或离线授权系统。

## 启动与停止

先按仓库说明准备专用.venv，开发实例使用`dev_publish.ps1`。已有虚构本地快照后，维护脚本生成仓库外全新测试根：

```powershell
.\.venv\Scripts\python.exe scripts/setup_publish_test.py --root <仓库外新测试服务目录> --store <本地归档store_UUID> --project <本地项目ID>
.\scripts\start_publish_server.ps1 -Config <测试根/server.json> -Ready <仓库外ready.json> -Port <专用回环端口>
.\scripts\dev_publish.ps1 -DevRoot <新的隔离开发目录>
```

将publisher/reader/outsider配置中的port设置为实际ready端口，保持service/project/token不变。版本历史选择完整版本→“发布到测试服务”→选择对应私有身份配置→连接查询（显示明确来源/远端映射）→发布/重试→查询→下载到新目录。网络/文件操作在线程执行，基本命名启动不导入服务组件。当前界面偏验证用途，失败原因展示、已确认文件数量、取消和多目标状态体验尚未完善。

服务前台Ctrl+C正常退出，或`stop_publish_server.ps1 -Ready <同一ready文件>`；停止脚本核对PID命令行和ready路径才终止，不关闭其他软件。自动验收finally停止自建服务，未安装后台服务。ready不含凭据，身份配置不能截图/入Git。
