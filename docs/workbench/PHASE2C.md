## 安装与运行

在Phase 2C独立工作树执行，不能覆盖原正式目录或Phase 2B工作树：

```powershell
# 基础预览依赖及固定的本地WASM资源；安装允许联网
.\scripts\setup_cad.ps1
# 自动化/自生成样本另需可选fixture工具，只写自己的测试模型
.\scripts\setup_cad.ps1 -WithFixtures
.\scripts\dev_cad.ps1
.\scripts\test_workbench.ps1
.\.venv\Scripts\python.exe scripts\verify_cad.py --output '<新的仓库外目录>'
.\.venv\Scripts\python.exe scripts\verify_cad.py --output '<另一个新目录>' --minutes 30
```

开发入口默认使用 `%LOCALAPPDATA%/MechanicalWorkbenchDev/phase2c`，独立数据、设置、缓存和单实例身份；可传 `-DevRoot` 或 `-Smoke`。不改变正式默认路径。客户端运行不需要Node或OCP；Node/npm仅安装和验证资源，实际测试版本为24.16.0/11.13.0，没有全局升级。

## 功能与边界

原“项目文件 → 本地预览”入口支持GLB、PDF、STL、STEP/STP；继续复用原项目/文件身份和编号，保留打开/定位、命名及历史。各组件按需加载；缺少STEP资源时明确提示运行setup_cad，基础功能、GLB/PDF及STL无需该资源。

- **STL**：ASCII与Binary，二进制头以solid开头时按精确长度识别；只读取三角数据，法向按顶点绕序重算，退化三角略去并提示，全部退化/空/损坏/非有限顶点/超限拒绝。不推断STL单位，不承诺自动修复绕序、拓扑、孔洞或实体；原文件不改写。显示时明确“单位未知”。
- **STEP**：仅在隔离开发模式通过OCCT/WASM直接读取受控的自包含AP203/AP214/AP242；普通模式点击会提示使用dev_cad入口，仍保留系统打开。保留传入的网格层级/名称、实体和面颜色，输出标准化毫米后以glTF米比例显示。单位/颜色/多实体均有实际样本验证；三角网格不等于精确CAD测量。文件内PMI、曲线、尺寸公差、约束和参数历史不在验收范围；网格实体数量不是源文件全部语义实体数量。
- 原生SLDPRT/SLDASM/SLDDRW不解析，不调用SOLIDWORKS、转换/保存原工程或修改引用；不做云、账号、分享或安装包。

## 依赖、安全审查与隔离

沿用Qt/PyQt6 6.11栈、Online 3D Viewer0.18.0；新增固定 `occt-import-js0.0.23`（官方npm实际发布版本；上游main的0.0.24不是已发布包）。依赖锁定在cad-web/package-lock.json，JS/WASM的SHA-256在代码及第三方来源记录中校验。资源仅从官方registry安装到忽略的node_modules，不向Git提交WASM、DLL或模型。完整原许可保留于third_party/preview，客户端只从精确回环路由读取两个已验证资源，运行不依赖CDN。

审查发现OCCT历史解析漏洞（含CVE-2026-42476至42481）。候选原生8.0.1发行tag早于上游安全合并PR1514，不能用“版本较新”代替补丁确认；没有将其接入客户端读文件。WASM包也不宣称已修复所有原生漏洞，npm审计0项不覆盖这些内核漏洞。采用以下实际边界限制风险，仍不能承诺未知恶意文件绝对安全：

1. STL三角转换和STEP词法检查放在独立CPython进程，直接启动基础解释器，`-I -S`加显式受信模块路径，PID对应真实子进程。Windows Job限制1 GiB、15秒，取消/超时关闭进程；只传源文件内存快照，不传原始路径或数据库。
2. STEP几何只在WebWorker的WASM线性内存/MEMFS中解释，不运行原生CAD DLL，没有主机文件系统挂载、Python桥、凭据或系统命令接口。Worker可终止，完成即释放；页面切换/取消立即撤销旧路由并终止旧上下文。
3. 启动STEP前握手，在实际Chromium渲染PID上建立1 GiB Job限制，失败则拒绝解析；30秒超时。WASM自身内存声明最大2 GiB，操作系统进程预算更严格。没有关闭Qt/Chromium沙箱、Web安全或证书校验。
4. 独立无缓存、无持久Cookie profile；CSP仅STEP页增加必要的wasm-unsafe-eval及同源worker权限，不允许JS unsafe-eval。沿用网络拦截、外部导航/下载/权限拒绝和精确能力路由，不暴露目录或磁盘。Worker只读取当前input.step和必要脚本/WASM。
5. 文件读取前后大小、mtime和身份校验；拒绝UNC/映射网络盘、符号链接/联接/云占位、非普通文件；STL最多32 MiB/30万面；STEP最多16 MiB、10万词法实体、50万引用，拒绝可识别的外部文件依赖/引用段、方向边循环/过深链和异常长记录。WASM输出最多1000实体、100万顶点、30万实例三角面、64层层级、2048材质和4096实例绘制primitive；JSON最多2 MiB、完整显示快照32 MiB。退化/精度塌陷三角也拒绝，失败明确提示，不能仅因函数success或HTML加载就算显示成功。

Native OCP8.0.1.1.0只用于可选测试写入器，在独立fixture生成进程中生成我们的形体和STEP，从不读取用户CAD。正式客户端启动/预览不导入OCP。发行源、wheel哈希、许可及上游安全核对依据见 [组件记录](../../third_party/preview/README.md)。本轮未重新构建OCCT，也未把未确认补丁的原生解析当作安全后备路线。
