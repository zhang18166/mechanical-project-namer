# 分阶段计划与验收边界

需求依据：[REQUIREMENTS.md](REQUIREMENTS.md)。已实现及实际验证结果以 [BASELINE.md](BASELINE.md) 为准。本计划不承诺日期或虚构完成率。

| 阶段 | 范围与状态 | 验收标准 |
| --- | --- | --- |
| 0 安全接管 | 本轮已实现：备份、基线、隔离入口、文档；本轮结束即停止 | 原测试和隔离测试通过；独立目录恢复校验；实际开发启动；正式目录前后比对；无敏感新增提交内容 |
| 1 统一项目身份与只读本地清单 | 下一阶段最小任务，尚未实现 | 在隔离库内保留现有项目 ID/编号/历史，增加可供未来图纸库引用的稳定身份；本地清单引用同一项目，不创建第二套项目库；仅登记文件身份和元数据，导入前后真实文件名/目录/内容不变；失败回滚和重启不重复；原测试继续通过 |
| 2 本地预览技术验证 | 未来计划 | 核实组件许可证、版本和格式支持；按需加载 Qt WebEngine / Online 3D Viewer；仅使用虚构 GLB/PDF，断网可预览，基础命名启动不依赖引擎；标明预览用途限制 |
| 3 版本快照与可恢复发布协议 | 未来计划，先离线模拟 | 一份快照绑定源工程/GLB/PDF/清单和哈希；模拟中断、缺文件、校验失败、重试；上一完整版本不受影响，半成品不可见为已发布；先有恢复测试再连接远端 |
| 4 账号与远端索引 | 未来计划 | 管理员开户、停用、重置；默认拒绝和项目权限；下载/离线/分享独立授权；云与 NAS 分工落实；在单独测试环境验证，核实服务器及网络实际条件 |
| 5 下载、缓存、离线与分享 | 未来计划 | 文件/版本/哈希命中和损坏检测；容量清理保护工作区与保留副本；固定版本分享的期限/密码/撤销及访客只读；PDF、源文件分别授权；明确已下载文件无法追回 |
| 6 备份恢复与小范围试用 | 未来计划 | 数据库、完整版本清单及源工程的配套独立备份；隔离恢复演练及引用完整性；一台主编辑电脑验证；另行授权后才制定正式部署与迁移步骤 |

下一阶段只做阶段 1，先审查现有整数项目 ID、设备/模块代号变更和历史关联，再制定增量身份映射；实现和测试仅用隔离数据库与虚构文件。字段及迁移方案需明确后实施，不在本轮预先改 Schema。阶段 1 不接入三维引擎、腾讯云、飞牛、账号或发布服务，不迁移真实数据库，不重命名 CAD，也不改安装包。

待单独验证：真实 SOLIDWORKS 联动、真实 AI、安装/卸载、三维组件兼容性与性能、云/NAS 访问和灾难恢复。历史接管文档的通过记录不能替代后续对应环境的实际验收。
